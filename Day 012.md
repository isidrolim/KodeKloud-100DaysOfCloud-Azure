# 100 Days of Cloud Azure - Day 012: Add and Manage Tags for Azure Virtual Machines

## Scenario

The Nautilus DevOps team is migrating infrastructure to Microsoft Azure. During the migration, the team identified an existing Virtual Machine that was not properly tagged.

Azure resource tags help organize, identify, govern, and manage cloud resources using key-value metadata.

## Requirement

Add the following tag to the existing Azure Virtual Machine:

- **Virtual Machine:** `xfusion-vm`
- **Tag Name:** `Environment`
- **Tag Value:** `dev`
- **Method:** Azure Portal (GUI)

The final tag should be:

```text
Environment=dev
```

## Implementation

1. Sign in to the **Azure Portal**.

2. Search for:

   ```text
   Virtual machines
   ```

3. Open the existing Virtual Machine:

   ```text
   xfusion-vm
   ```

4. From the VM **Overview** page, locate the **Tags** section.

   Alternatively, navigate to:

   ```text
   Settings → Tags
   ```

5. Add a new tag using the following key-value pair:

   ```text
   Name:  Environment
   Value: dev
   ```

6. Review the tag carefully before saving.

7. Click:

   ```text
   Apply
   ```

   or **Save**, depending on the Azure Portal interface.

8. Wait for Azure to finish updating the resource.

## Verification

1. Open:

   ```text
   Virtual machines → xfusion-vm
   ```

2. Navigate to the VM's **Tags** section.

3. Verify that the following tag exists:

   ```text
   Environment : dev
   ```

4. Confirm that the tag is applied specifically to:

   ```text
   xfusion-vm
   ```

5. Run the KodeKloud challenge validation.

## Result

The required Azure resource tag was successfully added to the Virtual Machine:

- **VM:** `xfusion-vm`
- **Tag Key:** `Environment`
- **Tag Value:** `dev`
- **Deployment Method:** Azure Portal

The VM can now be identified as belonging to the development environment through its Azure resource metadata.

## Key Takeaways

- Azure tags are **key-value pairs** used to organize and classify cloud resources.
- An `Environment=dev` tag makes it easier to identify resources belonging to the development environment.
- Common production tagging strategies may include:

  ```text
  Environment = dev
  Application = web
  Owner = platform-team
  CostCenter = IT
  ManagedBy = terraform
  ```

- Tags are useful for resource organization, reporting, automation, governance, and cost management.
- Tags do not automatically inherit across every Azure resource relationship, so tagging standards should be applied deliberately.
- Changing a tag modifies resource metadata and does not require restarting the Virtual Machine.
- Consistent tagging becomes increasingly important as the number of cloud resources grows.
