# 100 Days of Cloud Azure - Day 009: Attach Network Interface Card (NIC) to Azure Virtual Machine

## Scenario

The Nautilus DevOps team is continuing its migration of services to Microsoft Azure. As part of the networking configuration, an existing Network Interface Card (NIC) needs to be attached to an existing Azure Virtual Machine.

## Requirement

Use the existing Azure resources:

- **Virtual Machine:** `devops-vm`
- **Network Interface:** `devops-nic`
- **Region:** `East US`
- **NIC Status Required:** Attached
- **Method:** Azure Portal (GUI)
- Ensure the VM has completed initialization before submitting the task.

## Implementation

1. Sign in to the **Azure Portal**.
2. Search for **Virtual machines**.
3. Open the existing VM:

   ```text
   devops-vm
   ```

4. Confirm that the VM has completed its initial deployment and initialization.

5. Before attaching another NIC, stop/deallocate the VM if Azure requires it:

   ```text
   Virtual Machine → Overview → Stop
   ```

6. Wait until the VM status shows:

   ```text
   Stopped (deallocated)
   ```

7. From the VM menu, navigate to:

   ```text
   Networking → Network settings
   ```

8. Locate the **Network interface** section and select:

   ```text
   Attach network interface
   ```

9. Select the existing NIC:

   ```text
   devops-nic
   ```

10. Confirm the attachment.

11. Wait for Azure to finish updating the VM networking configuration.

12. Return to the VM **Overview** page and start the VM again if it was stopped:

   ```text
   Start
   ```

13. Wait until the VM returns to the:

   ```text
   Running
   ```

   state.

## Verification

1. Open:

   ```text
   Virtual machines → devops-vm → Networking
   ```

2. Verify that the VM now lists:

   ```text
   devops-nic
   ```

3. Alternatively, search for **Network interfaces** in the Azure Portal and open:

   ```text
   devops-nic
   ```

4. Verify that the NIC is associated with:

   ```text
   devops-vm
   ```

5. Confirm that the NIC status is:

   ```text
   Attached
   ```

6. Confirm that `devops-vm` has completed initialization and is operational.

7. Run the KodeKloud challenge validation.

## Result

The existing Azure Network Interface Card was successfully attached to the Virtual Machine:

- **VM:** `devops-vm`
- **NIC:** `devops-nic`
- **Region:** `East US`
- **NIC Status:** Attached
- **Deployment Method:** Azure Portal

## Key Takeaways

- An Azure NIC provides the network connectivity between a Virtual Machine and an Azure Virtual Network.
- A VM can support multiple NICs when its selected VM size supports that capability.
- Azure may require a VM to be stopped and deallocated before an additional NIC can be attached.
- The additional NIC must be compatible with the VM's networking configuration.
- Attaching a NIC changes the VM's network topology, so production changes should be planned carefully to avoid connectivity disruption.
- After changing VM networking, always verify both the Azure resource association and the VM's operational state.
