# 100 Days of Cloud Azure - Day 001: Create SSH Key Pair via Azure CLI

## Scenario

The Nautilus DevOps team is beginning a phased migration of infrastructure to Microsoft Azure. As part of the initial setup, an SSH key pair is required for secure authentication to Azure virtual machines.

## Requirement

Create an SSH key pair with the following configuration:

- **Key Pair Name:** `xfusion-kp`
- **Key Type:** RSA
- **Platform:** Microsoft Azure
- **Method:** Azure CLI

## Implementation

First, verify the active Azure account and subscription:

```bash
az account show
```

Create the RSA SSH key pair:

```bash
az sshkey create \
  --name xfusion-kp \
  --resource-group <resource-group-name>
```

> Azure SSH key resources store the **public key** in Azure. The private key must be kept securely by the administrator and should never be committed to GitHub or another source-control repository.

## Verification

Confirm that the SSH key resource exists:

```bash
az sshkey show \
  --name xfusion-kp \
  --resource-group <resource-group-name> \
  --output table
```

Alternatively, list the SSH key resources:

```bash
az sshkey list \
  --resource-group <resource-group-name> \
  --output table
```

Verify that:

- The SSH key resource is named `xfusion-kp`.
- The key type is RSA.
- The resource exists in the expected Azure resource group.

## Result

The `xfusion-kp` RSA SSH key pair was successfully created using the Azure CLI.

The challenge validation completed successfully.

## Key Takeaways

- Azure SSH public keys can be managed as Azure resources using `az sshkey`.
- SSH keys provide secure public-key authentication for Linux virtual machines.
- The public key can safely be stored in Azure, while the private key must remain protected.
- Always verify the active Azure subscription and resource group before creating cloud resources through the CLI.
