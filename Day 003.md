# 100 Days of Cloud Azure - Day 003: Create VM using Azure CLI

## Scenario

The Nautilus DevOps team is migrating workloads to Microsoft Azure. As part of the migration, a new Linux Virtual Machine must be created entirely through the Azure CLI.

## Requirement

Create an Azure VM with the following configuration:

- **VM Name:** `xfusion-vm`
- **Image:** `Ubuntu2204`
- **VM Size:** `Standard_B2s`
- **Admin Username:** `azureuser`
- **Authentication:** SSH key
- **Disk Type:** `Standard_LRS`
- **Disk Size:** `30 GB`
- The VM must be in the **running** state after creation.

## Implementation

First, identify the existing resource group:

```bash
az group list --output table
```

Create the virtual machine:

```bash
az vm create \
  --resource-group <resource-group-name> \
  --name xfusion-vm \
  --image Ubuntu2204 \
  --size Standard_B2s \
  --admin-username azureuser \
  --generate-ssh-keys \
  --storage-sku Standard_LRS \
  --os-disk-size-gb 30
```

## Verification

Verify the VM configuration and power state:

```bash
az vm show \
  --resource-group <resource-group-name> \
  --name xfusion-vm \
  --show-details \
  --output table
```

Confirm specifically that the VM is running:

```bash
az vm get-instance-view \
  --resource-group <resource-group-name> \
  --name xfusion-vm \
  --query "instanceView.statuses[?starts_with(code, 'PowerState/')].displayStatus" \
  --output tsv
```

Expected result:

```text
VM running
```

Verify the OS disk configuration:

```bash
az vm show \
  --resource-group <resource-group-name> \
  --name xfusion-vm \
  --query "storageProfile.osDisk.{DiskSizeGB:diskSizeGb,StorageType:managedDisk.storageAccountType}" \
  --output table
```

Expected configuration:

```text
DiskSizeGB    StorageType
------------  -----------
30            Standard_LRS
```

## Result

The `xfusion-vm` virtual machine was successfully created through the Azure CLI with:

- Ubuntu 22.04
- `Standard_B2s` VM size
- `azureuser` administrator account
- SSH key authentication
- 30 GB `Standard_LRS` managed disk
- Running power state

## Key Takeaways

- `az vm create` can provision a complete Azure VM and its supporting resources from the CLI.
- `--generate-ssh-keys` provides SSH key-based authentication instead of passwords.
- `--storage-sku Standard_LRS` specifies Standard HDD locally redundant storage.
- `az vm get-instance-view` can be used to verify the actual VM power state.
- Always validate the deployed configuration rather than assuming a successful creation command means every requirement was satisfied.
