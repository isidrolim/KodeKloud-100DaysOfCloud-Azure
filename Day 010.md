# 100 Days of Cloud Azure - Day 010: Attach Public IP to Azure Virtual Machine

## Scenario

The Nautilus DevOps team has already provisioned an Azure Virtual Machine and a Public IP address. The next networking task is to associate the existing Public IP with the Virtual Machine's Network Interface Card (NIC), allowing the VM to have a public-facing IP address.

## Requirement

Use the existing Azure resources:

- **Virtual Machine:** `xfusion-vm-pip`
- **Public IP:** `xfusion-pip`
- **Method:** Azure Portal (GUI)
- Attach `xfusion-pip` to the network interface of `xfusion-vm-pip`.
- Verify that the VM is properly assigned the Public IP.

## Implementation

1. Sign in to the **Azure Portal**.

2. Search for **Virtual machines**.

3. Open the existing VM:

   ```text
   xfusion-vm-pip
   ```

4. From the VM menu, navigate to:

   ```text
   Networking → Network settings
   ```

5. Locate the **Network Interface** attached to the VM and open it.

6. From the NIC menu, navigate to:

   ```text
   Settings → IP configurations
   ```

7. Select the existing IP configuration, typically:

   ```text
   ipconfig1
   ```

8. Locate the **Public IP address** configuration.

9. Select **Associate** and choose the existing Public IP:

   ```text
   xfusion-pip
   ```

10. Click **Save**.

11. Wait for Azure to finish updating the network interface configuration.

## Verification

After the configuration has been saved:

1. Navigate back to:

   ```text
   Virtual machines → xfusion-vm-pip → Overview
   ```

2. Verify that a **Public IP address** is now displayed for the VM.

3. Open the VM's Network Interface and navigate to:

   ```text
   IP configurations → ipconfig1
   ```

4. Confirm that the associated Public IP is:

   ```text
   xfusion-pip
   ```

5. You can also open:

   ```text
   Public IP addresses → xfusion-pip
   ```

6. Verify that the Public IP is associated with the network interface used by:

   ```text
   xfusion-vm-pip
   ```

7. Run the KodeKloud challenge validation.

## Result

The existing Azure Public IP was successfully associated with the Virtual Machine:

- **VM:** `xfusion-vm-pip`
- **Public IP Resource:** `xfusion-pip`
- **Association:** VM NIC IP configuration
- **Deployment Method:** Azure Portal

The VM is now properly assigned the required Public IP address.

## Key Takeaways

- In Azure, a Public IP is normally associated with a VM through the VM's **Network Interface Card (NIC)** rather than directly with the VM itself.
- The relationship is:

   ```text
   Public IP
       ↓
   NIC IP Configuration
       ↓
   Network Interface
       ↓
   Virtual Machine
   ```

- The NIC's IP configuration manages both private and optional public IP associations.
- Assigning a Public IP provides an internet-routable address, but it does **not automatically allow inbound traffic**.
- Network Security Group (NSG) rules still determine which inbound ports and protocols are permitted.
- In production environments, Public IP exposure should be minimized and only enabled when there is a clear requirement.
