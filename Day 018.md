# 100 Days of Cloud Azure - Day 018: Copy Data to an Azure Blob Storage Container

## Scenario

The Nautilus DevOps team is migrating data from on-premises storage systems to Microsoft Azure Blob Storage.

An Azure Storage Account and Blob container already exist. The task is to upload an existing local file from the Azure client host into the designated Blob container.

## Requirement

Use the following existing resources:

- **Storage Account:** `datacenterst66810006`
- **Blob Container:** `datacenter-blob-66810006`
- **Region:** `East US`
- **Source File:** `/tmp/datacenter.txt`
- **Destination Blob:** `datacenter.txt`

Copy:

```text
/tmp/datacenter.txt
```

into:

```text
datacenterst66810006
└── datacenter-blob-66810006
    └── datacenter.txt
```

## Implementation

### 1. Verify the Source File

Before copying anything, verify that the required source file exists on the Azure client host:

```bash
ls -lh /tmp/datacenter.txt
```

Optionally inspect the file:

```bash
cat /tmp/datacenter.txt
```

This confirms that the source data exists before attempting the upload.

### 2. Verify the Existing Azure Resources

Confirm that the required storage account exists:

```bash
az storage account show \
  --name datacenterst66810006 \
  --output table
```

Verify that the target Blob container exists:

```bash
az storage container show \
  --name datacenter-blob-66810006 \
  --account-name datacenterst66810006 \
  --auth-mode login \
  --output table
```

### 3. Upload the File to Azure Blob Storage

Upload the local file into the existing Blob container:

```bash
az storage blob upload \
  --account-name datacenterst66810006 \
  --container-name datacenter-blob-66810006 \
  --name datacenter.txt \
  --file /tmp/datacenter.txt \
  --auth-mode login
```

The data path is now:

```text
Azure Client
    │
    │ /tmp/datacenter.txt
    ▼
Azure Storage Account
    │
    └── datacenterst66810006
          │
          └── datacenter-blob-66810006
                │
                └── datacenter.txt
```

## Verification

List the blobs in the target container:

```bash
az storage blob list \
  --account-name datacenterst66810006 \
  --container-name datacenter-blob-66810006 \
  --auth-mode login \
  --output table
```

Verify that the following blob is present:

```text
datacenter.txt
```

For a more focused verification:

```bash
az storage blob show \
  --account-name datacenterst66810006 \
  --container-name datacenter-blob-66810006 \
  --name datacenter.txt \
  --auth-mode login \
  --output table
```

Confirm:

```text
Storage Account: datacenterst66810006
Container:       datacenter-blob-66810006
Blob:            datacenter.txt
Upload:          Successful
```

## Result

The local data file was successfully copied to Azure Blob Storage:

```text
/tmp/datacenter.txt
        │
        ▼
datacenterst66810006
        │
        ▼
datacenter-blob-66810006
        │
        ▼
datacenter.txt
```

The file is now stored as a Blob within the required Azure container.

## Key Takeaways

- Azure Blob Storage provides object storage for files and other unstructured data.
- `az storage blob upload` uploads a local file into an Azure Blob container.
- The **storage account** provides the top-level storage namespace.
- The **container** organizes related blobs within the storage account.
- The `--file` parameter identifies the local source file, while `--name` defines the destination Blob name.
- `--auth-mode login` uses the authenticated Azure identity instead of requiring storage account keys.
- Before performing a data migration, verify both ends of the dependency path: the local source file and the destination storage resources.
- After an upload, independently list or inspect the destination Blob rather than relying only on the upload command's success message.
