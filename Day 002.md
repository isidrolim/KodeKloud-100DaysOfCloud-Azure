# 100 Days of Cloud Azure - Day 002: Create Azure Virtual Machine via Azure CLI

## Scenario

The Nautilus DevOps team is migrating part of its infrastructure to Microsoft Azure incrementally. As part of the migration, an Ubuntu Linux Virtual Machine needs to be deployed using the existing Azure resource group.

## Requirement

Create an Azure Virtual Machine with the following configuration:

- **VM Name:** `datacenter-vm`
- **Region:** `centralus`
- **Operating System:** Ubuntu 24.04 LTS
- **VM Size:** `Standard_B1s`
- **Network Security Group:** Default NSG allowing inbound SSH
- **SSH Port:** `22`
- **OS Disk Size:** `30 GB`
- **Disk Type:** Standard HDD
- **Other Settings:** Default
- Verify that the VM can be accessed successfully through SSH.

## Implementation

First, identify the existing resource group:

```bash
az group list --output table
```

Create the Azure VM using the required configuration:

```bash
az vm create \
  --resource-group <resource-group-name> \
  --name datacenter-vm \
  --location centralus \
  --image Ubuntu2404 \
  --size Standard_B1s \
  --os-disk-size-gb 30 \
  --storage-sku Standard_LRS \
  --admin-username azureuser \
  --generate-ssh-keys
```

Allow inbound SSH traffic on TCP port `22`:

```bash
az vm open-port \
  --resource-group <resource-group-name> \
  --name datacenter-vm \
  --port 22
```

## Verification

Verify that the VM was successfully created and is running:

```bash
az vm show \
  --resource-group <resource-group-name> \
  --name datacenter-vm \
  --show-details \
  --output table
```

Retrieve the VM's public IP address:

```bash
az vm show \
  --resource-group <resource-group-name> \
  --name datacenter-vm \
  --show-details \
  --query publicIps \
  --output tsv
```

Connect to the VM using SSH:

```bash
ssh azureuser@<PUBLIC-IP>
```

After connecting, verify the VM identity and network configuration:

```bash
hostname
ip a
```

The SSH session confirmed successful access to:

```text
azureuser@datacenter-vm
```

The VM received its private Azure VNet address and its network interface was operational.

## Result

The `datacenter-vm` Azure Virtual Machine was successfully deployed with:

- Ubuntu 24.04 LTS
- `Standard_B1s` VM size
- 30 GB Standard HDD OS disk
- Network Security Group permitting SSH on TCP/22
- Working SSH connectivity

The KodeKloud challenge validation completed successfully. ✅

## Key Takeaways

- `az vm create` can provision the VM and its supporting Azure networking resources from a single CLI command.
- VM size controls the compute resources assigned to the instance.
- `Standard_LRS` provides Standard HDD-backed Azure managed disk storage.
- An NSG rule must permit TCP/22 before SSH traffic can reach the VM.
- Successful resource creation alone is not enough—SSH connectivity should be tested as an end-to-end validation.
- `az vm show --show-details` is useful for quickly checking VM state and IP information.
